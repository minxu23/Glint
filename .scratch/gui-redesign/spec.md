# 图形界面重做：图片管理 + 格式转换（设计规格）

Status: ready-for-agent

对象是 `Sources/GUI/`（AppKit）。`Sources/Core/` 和命令行的行为不变。
可视化参照：[`mockup.html`](mockup.html)（浏览器打开，A–D 四张）。草图只定排版、层级和文案；
真实界面一律用 AppKit 的系统控件、系统色、系统字体，草图里的色值只是系统色的近似，不要照抄。
草图里的缩略图是色块，真实界面是照片。

## 1. 这是什么

一个看得见自己照片的 Mac 应用：左边是文件夹，中间是缩略图，右边是选中那张的信息（拍摄时间、
位置、相机、**备注**）。在这之上能把 JPEG 转成 HEIF，转完逐项校验，差异摆在明面上。

第一版的范围（用户已定）：

- **浏览、查看、转换。不改动照片**：不重命名、不移动、不删除（转换时「校验无差异后删除源文件」
  除外）、不编辑备注。
- 转换的目标格式做成一个下拉框，**第一版只有 HEIF 一项**，以后再加别的；能转的源只有 JPEG。
- 浏览的是磁盘上的文件夹，不接「照片」App 的图库。

设计上只有两处用力，别处安静：

1. 照片本身是主角，界面的框架尽量退后；
2. 备注在哪、会不会丢，说清楚——这是用户最在意的东西。

## 1.1 名字

应用叫**吉光**（取自「吉光片羽」：留存下来的珍贵片段——照片，连同它的拍摄时间、位置和备注）。
用户看得到应用名的地方都用它：`Info.plist` 的 `CFBundleName` / `CFBundleDisplayName`、应用菜单
（关于吉光、隐藏吉光、退出吉光）、关于面板、没有选中条目时的窗口标题、README。应用包是 `吉光.app`。
`CFBundleIdentifier`、可执行文件名、命令行工具 `jpeg2heif`、仓库名都不变。

实现上改名只动两处：代码里一个常量（菜单、关于面板、窗口标题都引用它），`Makefile` 里一个变量
（应用包名，`Info.plist` 的 `CFBundleName` / `CFBundleDisplayName` 与它一致）。

## 2. 约束

- AppKit，纯代码（没有 xib、没有资源目录），`swiftc` + Command Line Tools 能编；零第三方依赖。
  系统框架可以用（ImageIO、Quartz 的 `QLPreviewPanel`、UniformTypeIdentifiers 等）。
- 不依赖 UI 框架的逻辑放进可以单测的模型层，由 `Tests/guimodel` 测；视图只做呈现。
  现有的 `ConversionModel`（`Model.swift`）继续当转换的调度器用，可以扩展，不要推倒重写它
  已有的行为和测试。
- 中文界面。浅色、深色、「增强对比度」都要对：颜色只用语义色，不写死色值；跟随系统强调色。
- 字体用系统字体，数字用 `monospacedDigitSystemFont`；图标用 SF Symbols；不用 emoji。
- 主线程上不做任何读图、读元数据、扫目录的事。

## 3. 窗口结构

默认 1180×720，最小 900×560。`NSSplitViewController` 三栏 + 统一样式的工具栏；侧栏和信息栏用
系统的 sidebar / inspector 分栏行为，可以各自收起。窗口大小、位置、分栏宽度记住。

```
┌───────────┬───────────────────────────────────────────────┬──────────────┐
│ ● ● ●     │ 2026 春                 [▦|☰] [⇅] [搜索……] [转换…] [▯] │   工具栏      │
│           │ 248 张，其中 JPEG 196 张，共 612 MB                  │              │
│ 图库      ├───────────────────────────────────────────────┼──────────────┤
│  全部图片  │ ▢ ▢ ▢ ▢ ▢                                      │  预览         │
│  可以转换  │ ▢ ▢ ▢ ▢ ▢        缩略图网格（或列表）            │  文件名       │
│  有备注    │ ▢ ▢ ▢ ▢ ▢                                      │  备注         │
│ 转换      │ ▢ ▢ ▢ ▢ ▢                                      │  拍摄         │
│  最近一次… │                                               │  文件         │
│ 文件夹     │                                               │  （转换结果）  │
│  Pictures │                                               │              │
│   2026 春 │                                               │              │
│ ＋添加文件夹…├───────────────────────────────────────────────┴──────────────┤
│           │ 正在转换  已转 82 张，共 196 张        ▓▓▓░░░░   [取消]        │ 活动条
└───────────┴──────────────────────────────────────────────────────────────┘
```

- 侧栏 208pt，信息栏 280pt，中间弹性。
- 活动条**只在转换进行中和刚转完时出现**（高 40），平时没有底栏。
- 整个窗口接受拖放：拖进文件夹就加到「文件夹」；拖进单张图片归到一个「单独添加的图片」条目。

## 4. 侧栏

`NSOutlineView`，source list 样式。每一项右边有张数（次要色、等宽数字）。

- **图库**
  - 全部图片：所有已添加文件夹里的图片
  - 可以转换：其中的 JPEG
  - 有备注：能读到任何一种备注的（第 7.2 节）
- **转换**（做过转换才出现）
  - 最近一次转换：这次运行里最后一批；下面两个子项「有差异」「失败」，为零的不显示
- **文件夹**
  - 用户加进来的文件夹，可展开看子文件夹（只列里面有图片的）。选中一个文件夹 = 看它和它所有
    子文件夹里的图片。
  - 右键：在访达中显示 / 从侧栏移除（只是不再显示，不动磁盘）
- 底部一个 `添加文件夹…`。

加进来的文件夹记住（`UserDefaults` 存路径；路径不存在了就在名字后面标「找不到」并置灰）。
转换记录只在本次运行里有，不存盘。

## 5. 工具栏

从左到右：标题（当前条目的名字）和副标题（`248 张，其中 JPEG 196 张，共 612 MB`；有选中时
`选中 3 张，共 6.6 MB`）；弹性空白；网格/列表切换；排序菜单（拍摄时间、文件名、大小、格式；
升/降）；搜索框（占位文字 `搜索文件名和备注`）；`转换…`（唯一一个强调色按钮）；信息栏开关。

`转换…` 的对象：有选中就是选中的那些里的 JPEG，没选中就是当前视图里全部的 JPEG。
一张能转的都没有时按钮禁用，悬停提示 `这里没有可以转换的 JPEG`。转换进行中也禁用。

## 6. 中间：网格与列表

### 6.1 网格（默认）

`NSCollectionView`，方形单元，等比裁切居中，圆角 7，间距 10，四周留白 14。单元边长可调
（工具栏不放滑杆；用 `显示` 菜单的 `放大` ⌘+、`缩小` ⌘−，以及触控板捏合；范围 96–320，默认 168，
记住）。

缩略图上**默认什么都不叠**。只有三种情况在角上放一个小标记：

| 位置 | 标记 | 什么时候 |
|---|---|---|
| 右下 | `text.alignleft` 白色图标，半透明深色圆角底 | 这张有备注 |
| 右上 | 白色圆底 + `exclamationmark.triangle.fill`（systemOrange） | 这次运行里转过，有差异 |
| 右上 | 白色圆底 + `xmark.circle.fill`（systemRed） | 这次运行里转换失败 |
| 右上 | 白色圆底 + 转圈 | 正在转换 |

转换成功且无差异的不加标记——正常的要安静，例外的才显眼。不叠格式角标（一个文件夹里往往
绝大多数都是同一种格式，角标只是噪声；格式看副标题、列表和信息栏）。

选中：单元外描一圈强调色的边（3pt，离图 2pt）。支持框选、⌘ 点选、⇧ 连选、方向键移动。

- 空格：Quick Look 预览（`QLPreviewPanel`），再按一次关闭；
- 双击 / ⌘O：用默认应用打开；
- 右键：转换…（是 JPEG 才有）/ 用默认应用打开 / 在访达中显示 / 拷贝路径。

缩略图后台生成（ImageIO，按单元的像素尺寸取，带缓存；滚出屏幕的取消；并发数有上限），
没出来之前是一块 `quaternaryLabelColor` 的底，不放转圈。

### 6.2 列表

`NSTableView`，行高 40，有表头，点表头排序。列：名称（28×28 缩略图 + 文件名，中间截断）、
拍摄时间、格式、尺寸、大小、备注（有就显示第一条的开头，单行，尾部截断）、转换（这次运行里
转过才有内容：`无差异` / `N 处差异` / `失败` / `转换中`，前面带与网格相同的图标；图标带颜色，
文字不用彩色）。任何宽度下文件名都不许压到别的列。

键盘、右键、Quick Look 与网格相同。网格和列表共用选中状态，切换时保持。

### 6.3 空状态

- 一个文件夹都没加：居中 `photo.on.rectangle.angled`（46pt，三级色）、标题
  `把装照片的文件夹拖进来`（17pt 半粗）、说明 `在这里看照片的拍摄时间、位置和备注，把 JPEG 转成更省空间的 HEIF。`
  、按钮 `添加文件夹…`。不画虚线框。
- 当前条目里没有图片：`这里没有图片`。
- 搜索没结果：`没有找到「关键词」`。
- 正在扫描一个大文件夹：先出来的先显示，副标题末尾写 `正在读取…`。

## 7. 信息栏

### 7.1 选中一张

从上到下，每组之间一条分隔线；某一组没有内容就整组不显示（不放「无」）：

1. 预览（宽度撑满，高 168，等比裁切，圆角 7）、文件名（14pt 半粗，可换行）、一行
   `JPEG，4096 × 3072，3.3 MB`（11pt 次要色）。
2. **转换结果**（这次运行里这张转过，或者它是这次转出来的产物才有）：
   - 标题行，带状态图标：`转换时无差异` / `转换时有 N 处差异` / `没有校验` / `转换失败`；
   - 差异逐条列出：以 `丢失 ` 开头的标 `丢失`（systemRed），以 `变化 ` 开头的标 `变化`
     （systemOrange），其它标 `注意`（次要色）；正文去掉开头那两个字，可选中、自动折行；
     下面一个小按钮 `拷贝全部`；
   - 两列明细：体积（`3.3 MB → 989 KB`，下一行 `省 71%` 或 `比源文件大 33%`）、
     EXIF（复用 `ConversionReport.rawExif` 已有的描述）、源文件（`还在` + `在访达中显示`，或
     `已删除`）；重编、写入备注的结果（`ConversionReport.reencode` / `.caption`）有才显示；
     `ConversionReport.note` 非空时原文照显。
   - 选中的是还在的源 JPEG 时，这一组写 `已转成 HEIF`，下面 `显示转出的文件`（选中那张 HEIF）。
3. **备注**（第 7.2 节）。
4. **拍摄**：时间（`2026 年 4 月 27 日 20:28`）、相机（型号；下一行小字
   `f/1.4，1/50 秒，ISO 640，24 mm`，有几项写几项）、镜头（有才显示）、位置
   （`51.0530° N，13.7343° E`，下面 `在地图中打开`，用 `maps://` 链接）。
5. **文件**：所在文件夹（`~` 缩写，点它在访达中显示）、修改时间。

### 7.2 备注：都读哪些、怎么说

「备注」是界面上的统称。读这几处，读到几条显示几条，每条下面一行小字说明它存在哪：

| 来源 | 怎么读 | 下面那行小字 |
|---|---|---|
| 「照片」App 的说明 | 扩展属性 `com.apple.assetsd.description`（UTF-8） | ⚠ `存在文件之外，换设备或传网盘容易丢`（systemOrange 的三角图标，文字次要色） |
| 访达备注 | 扩展属性 `com.apple.metadata:kMDItemFinderComment`（二进制 plist 里的字符串） | 同上 |
| 文件里的说明 | ImageIO 视图的 `XMP dc:description` / `{IPTC}/Caption/Abstract` / `{TIFF}/ImageDescription`，同值只显示一条 | `存在文件里` |
| EXIF 备注 | `{Exif}/UserComment`；ImageIO 读不出或读成乱码时用 Core 的 `readUserComment`（只取「可靠的」那种） | `存在文件里（EXIF 备注）` |

同一段文字在文件内外都有时只显示一条，小字写 `文件里外各有一份`。备注文字 13pt、行高 1.5、
可选中，超过 12 行折叠成 `显示全部`。

### 7.3 选中多张 / 没选中

- 多张：`选中 12 张`，下面格式分布（`JPEG 10 张，共 31 MB` / `HEIF 2 张，共 4 MB`）、
  `有备注 3 张`。
- 没选中：当前条目的汇总，同样的格式分布和有备注的张数；当前是「最近一次转换」时再加
  转换汇总：`转完 195 张，省下 398 MB`、`412 MB → 14 MB` 这类总量、各类张数（无差异 / 有差异 /
  没有校验 / 已跳过 / 失败 / HEIF 比源文件大，零的不显示）、`最常见的差异` 前 5 条
  （归并规则：每行取到第一个 ` = `、`: `、`：` 为止，连续数字换成 `N`；一张图里相同的只算一次）。

## 8. 转换

### 8.1 面板

点 `转换…` 从工具栏下滑出一个 sheet（宽 460）：

- 标题 `转换 196 张 JPEG`；下面一行说清对象：`「2026 春」里的全部 JPEG，共 587 MB。别的格式不动。`
  或 `选中的 3 张 JPEG，共 6.6 MB。`
- 转成：下拉框，只有 `HEIF（.heic）` 一项（留给以后加格式；不要因为只有一项就做成静态文字）。
- 画质：滑杆 + 数值 + 提示语（现有的取值范围和提示语保留）。
- 保存到：下拉框 `源文件旁边` / `指定文件夹…`；选了文件夹显示路径。转整个文件夹到指定位置时
  按原来的子目录结构摆放（Core 已有的行为）。
- 元数据
  - ☑ 转完逐项校验 —— `比对拍摄时间、位置、备注和扩展属性，列出丢失或变化的每一项`
  - ☐ 把备注写进文件 —— `这批里有 12 张的备注存在文件之外，写进去以后换了设备也在`
    （数字是这批里有「照片」说明、而文件里没有说明的张数；是 0 时写
    `这批里没有存在文件之外的备注` 并禁用）。对应 `ConversionOptions.embedCaption`。
- 源文件
  - ☐ 校验无差异后删除源文件 —— `有差异的、HEIF 反而更大的，源文件都留着`
    勾上后：自动勾上并锁住「转完逐项校验」；下面多一行 `删除后不进废纸篓`（以 Core 的实际行为
    为准）；主按钮变成 `转换并删除源文件`（破坏性样式）。
- `高级`（折叠，默认收起；这批里有 CMYK 的 JPEG 时展开）：☐ EXIF 交给系统重写 —— `默认把源文件的 EXIF 原样搬过去。个别软件读不了这样的文件时再勾`
  （`ConversionOptions.rawExif = false`）；☐ 覆盖同名的 HEIF；☐ 也转 CMYK 的 JPEG ——
  `这批里有 N 张 CMYK 的 JPEG。HEIF 只能存 RGB，转了颜色会变；不勾就跳过`
  （`ConversionOptions.convertCMYK`，同 `jpeg2heif --allow-cmyk`）。
- 按钮：`取消`（Esc）、`转换`（回车）。

记住上次的设置：画质、保存到、逐项校验、把备注写进文件、高级里的 EXIF 那一项。
**「删除源文件」「覆盖同名的 HEIF」「也转 CMYK 的 JPEG」不记**，每次打开面板都是关的。

### 8.2 进行中

- 面板收起，活动条出现：`正在转换　已转 82 张，共 196 张` + 进度条 + `取消`。
- 正在转的缩略图右上角转圈；转完有差异或失败的立刻换成对应标记。
- 转换期间可以照常浏览、选中、看信息；`转换…` 禁用。
- 侧栏出现「转换 › 最近一次转换」，数字跟着涨。

### 8.3 转完

- 活动条换成一句话 + `好`（点了收起）：
  `转完 195 张，省下 398 MB。9 张有差异，1 张失败，它们的源文件都还在。`（没有的类不写；
  没开删除就不提源文件；取消了的写 `已取消。转完 82 张，还有 114 张没转。`）
  句子里 `9 张有差异` 可以点，点了跳到「最近一次转换 › 有差异」。
- 重新扫描受影响的文件夹，新出来的 HEIF 出现在网格里。
- 「最近一次转换」里显示这一批：有产物的显示产物（HEIF），没有产物的（失败、跳过）显示源文件。
- 应用不在前台时 `NSApp.requestUserAttention(.informationalRequest)`。不发系统通知。

## 9. 菜单与键盘

菜单栏在现有基础上：

- 文件：`添加文件夹…` ⇧⌘O；`打开` ⌘O；`在访达中显示` ⇧⌘R；`转换…` ⌘E；`取消转换` ⌘.
- 编辑：`拷贝`（选中图片时拷贝文件；焦点在文字上时拷贝文字）、`全选` ⌘A
- 显示：`网格` ⌘1、`列表` ⌘2、`放大` ⌘+、`缩小` ⌘−、`显示/隐藏侧栏` ⌃⌘S、`显示/隐藏信息栏` ⌥⌘I、
  `重新读取` ⌘R
- 窗口、帮助照旧。

`⌘F` 进搜索框；Tab 在侧栏、网格、信息栏之间走。菜单项按状态启用/禁用。

## 10. 无障碍

- 每个缩略图单元有完整的描述：`IMG_2026.jpg，JPEG，3.3 MB，有备注，转换时有 2 处差异`。
- 角上的标记不靠颜色单独传达：形状不同（三角、叉、文字图标），描述里有文字。
- 纯图标的工具栏按钮都有标签和悬停提示。
- 「减弱动态效果」打开时不做过渡动画。本设计只有三处动画：面板滑出（系统的）、活动条出现/收起、
  标记淡入（150ms）。

## 11. 模型层（要能单测的部分）

名字你定，职责如下，都不依赖 AppKit：

- **图库**：来源（文件夹、单独的文件）→ 扫描（递归，只收图片：按 UTType 是否符合 `public.image`）
  → 条目列表；按侧栏条目过滤、排序、搜索（文件名和备注，不分大小写）；各条目的张数；
  副标题那句话；多选/未选时的汇总（7.3）。扫描和读元数据要能注入假的实现来测。
- **条目信息的读取**：文件大小、修改时间、格式、像素尺寸、拍摄时间、相机与参数、位置、备注
  （7.2 的四种来源、去重规则、「文件里外各有一份」的判定）。分两步：先列文件（快），再后台
  补元数据，补到哪显示到哪。
- **转换的对象**：从选中/当前视图算出要转的 JPEG，带上各自的来源根目录（给 Core 的 `Job`
  镜像目录结构用）；面板标题和说明那两句话；「这批里有几张的备注存在文件之外」。
- **转换记录**：每个源对应的结果（沿用/扩展 `FileRow`，补上 `rawExif`、`reencode`、`caption`）；
  产物与源的对应；「最近一次转换」及其子项；汇总与「最常见的差异」；活动条每种情形的那句话；
  差异行分成（标记，正文）。
- **设置的读写**：注入存储，好测「删除源文件」「覆盖」不被记住。

## 12. 验收

   转换记录的各类计数、总体积、产物总体变大、取消；活动条的每一句话；设置持久化。

## 13. 不做的

- 不改 `Sources/Core/`、命令行的行为和输出（可以**调用** Core 里现成的函数）。
- 不重命名、移动、删除照片，不编辑备注；不接「照片」图库；不做地图视图、时间线、相簿、标签。
- 不做 JPEG → HEIF 以外的转换；不做偏好设置窗口；不发系统通知；不监视文件夹变化
  （切回应用、转完、⌘R 时重新读取即可）。
- 不换成 SwiftUI。
